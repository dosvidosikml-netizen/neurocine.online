# NeuroCine v49 — Account Scoped Drafts Fix

## Что исправлено

- Локальный черновик сценария/темы/storyboard больше не общий для всех Google-аккаунтов в одном браузере.
- `localStorage` теперь разделён по `user.id` Supabase.
- При выходе/входе другим аккаунтом рабочая область сбрасывается и загружает только черновик текущего пользователя.
- Production Pack local cache также разделён по пользователю.
- Старые глобальные ключи `nc_text_v3` / `nc_imgs_v3` больше не читаются.
- Зависшие busy-состояния сбрасываются при смене аккаунта.

## Файлы для замены

- `app/storyboard/page.js`
- `components/ProductionPack.js`
- `README_v49_account_scoped_drafts.md`

## Проверка

1. Войти админом, создать сценарий.
2. Выйти.
3. Войти другим Google-аккаунтом.
4. В Studio не должно быть текста/истории админского аккаунта.
5. Создать свой DEMO сценарий.
6. Выйти/войти обратно этим же аккаунтом — его личный черновик должен восстановиться.
