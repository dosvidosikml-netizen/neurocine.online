# NeuroCine Wake

Минимальное Android-приложение для Wake-on-LAN под ПК NeuroCine.

## Уже вставлено

- MAC ПК: `70:85:C2:98:35:76`
- Broadcast IP домашней сети: `192.168.0.255`
- Wi-Fi Port: `9`
- Remote IP роутера на момент проверки: `5.182.97.164`
- Remote UDP Port: `40009`

На экране эти поля можно поменять вручную, если сменится роутер или подсеть.

## Как работает

Кнопка `Разбудить дома по Wi-Fi` отправляет 5 Wake-on-LAN magic packets на `192.168.0.255:9`.

Кнопка `Разбудить удалённо через роутер` отправляет 5 Wake-on-LAN magic packets на внешний адрес роутера `5.182.97.164:40009`.

Лучший первый тест:

1. Телефон подключён к домашнему Wi-Fi.
2. ПК в sleep или выключен, но кабель Ethernet и питание остаются подключены.
3. В BIOS включён Wake-on-LAN / Power On by PCI-E.
4. Нажать `Разбудить ПК`.

## Для включения издалека

Android-приложение сможет будить ПК из мобильного интернета только если роутер или другое устройство дома передаст magic packet в локальную сеть.

Рекомендуемая схема для TP-Link:

1. В роутере найти `Forwarding / Virtual Servers` или похожий раздел.
2. Создать UDP правило:
   - external/public port: `40009`
   - internal port: `9`
   - protocol: `UDP`
   - internal IP: если роутер разрешает broadcast, `192.168.0.255`; если не разрешает, `192.168.0.104`
3. Если выбран `192.168.0.104`, желательно закрепить IP ПК в DHCP reservation по MAC `70:85:C2:98:35:76`.
4. Если роутер имеет отдельный раздел `Wake-on-LAN`, лучше использовать его: MAC `70:85:C2:98:35:76`.

Если TP-Link не пропускает broadcast WOL после выключения ПК, остаются варианты:

- VPN домой, чтобы телефон оказался как будто в домашней сети;
- роутер умеет Wake-on-LAN из своего приложения/админки;
- домашний relay-сервер в сети;
- умная розетка + BIOS `Power On after AC restore`.

Самый надёжный вариант без зависимости от WOL роутера: умная розетка + BIOS `Power On after AC restore`. После включения Windows Local Agent уже настроен на автозапуск.

## Сборка APK

На текущем ПК Java, Android SDK и Gradle уже установлены. Сборка:

```powershell
cd tools\neurocine-wol-android
gradle assembleDebug
```

APK будет здесь:

```text
tools\neurocine-wol-android\app\build\outputs\apk\debug\app-debug.apk
```
